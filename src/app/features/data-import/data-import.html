ارفع ملف Excel أو JSON لنقل المخزون من نظامكم الحالي. الماركات والفئات والمنتجات تُحدَّث إن وُجدت أو تُنشأ إن لم توجد — بدون تكرار لنفس العنصر المنطقي.

قواعد الدمج (Upsert)
  • ماركة / فئة: مطابقة بالاسم (بدون تمييز حالة الأحرف) → موجود = استخدام، غير موجود = إنشاء.
  • منتج: مطابقة بـ SKU إن وُجد، وإلا بـ (ماركة + موديل + فئة + قطعة + درجة الجودة) → موجود = تحديث، غير موجود = إنشاء.
  • سعر التكلفة (costPrice) لا يُستورد — يُحدَّث عبر استلام أوامر الشراء.
